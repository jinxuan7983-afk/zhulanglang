高校学科竞赛报名管理系统
数据库设计说明书
一、引言
1.1 编写目的
本文档是"高校学科竞赛报名管理系统"的数据库设计说明书，旨在：
1. 明确数据需求 ：基于需求规格说明书，系统分析业务功能对数据存储、	管理和查询的要求，识别核心数据实体及其属性。
2. 规范开发流程 ：明确数据库设计的步骤、范式要求和完整性约束，确保	数据库结构合理、数据一致性良好，满足系统功能需求。
3. 提供团队协作依据 ：为开发团队提供统一的数据字典和实体关系说明，	便于前后端开发人员理解数据结构，协调开发工作。
4. 支持系统维护 ：作为系统后期维护、扩展和优化的参考文档，帮助维护	人员快速理解数据库结构和设计思路。
1.2 适用范围
本文档适用于以下人员和场景：
数据库开发人员 ：根据本文档进行ER图绘制、关系模式设计和建表实现
后端开发人员 ：根据数据实体和属性定义编写业务逻辑和数据访问层代码	前端开发人员 ：根据数据字段定义设计数据展示和交互界面
测试人员 ：根据数据约束和业务规则设计测试用例
项目管理人员 ：了解数据库设计进度和关键设计决策

3.1 关系模式设计
3.1.1 用户表（user）
关系模式 ：
user (
user_id BIGINT,
student_no VARCHAR(50),
email VARCHAR(100),
password VARCHAR(255),
name VARCHAR(50),
college VARCHAR(100),
phone VARCHAR(20),
avatar VARCHAR(255),
role ENUM('student','teacher','admin'),
status ENUM('normal','locked'),
lock_until DATETIME,
login_fail_count INT,
create_time DATETIME,
update_time DATETIME,
PRIMARY KEY (user_id),
UNIQUE (student_no),
UNIQUE (email)
)
主键 ：user_id
外键 ：无
3.1.2 竞赛表（contest）
关系模式 ：
contest (contest_id, 
name, 
category, 
level, 
registration_start, 
registration_end, 
contest_time, location, 
organizer, cover_image, 
attachment_url,

create_by, 
create_time,

is_deleted
)
主键 ：contest_id
外键 ：无
3.1.3 报名表（enrollment）
关系模式 ：
enrollment(
enrollment_id, 
user_id, 
contest_id, s
tatus, 
review_comment, 
registration_time, 
review_time, 
reviewer_id, 
attachment_url
)
主键 ：enrollment_id
外键 ：- contest_id → contest(contest_id)
user_id → user(user_id)
team_id → team(team_id)（可空，个人赛时为空）
reviewer_id → user(user_id)（可空，未审核时为空）
3.1.4 团队表（team）
关系模式 ：
team (
team_id BIGINT,
contest_id BIGINT,
captain_id BIGINT,
team_name VARCHAR(100),
invite_code VARCHAR(6),
create_time DATETIME,
status ENUM('pending','reviewing','approved','rejected'),
registration_material VARCHAR(255),
review_comment VARCHAR(500),
submit_time DATETIME,
review_time DATETIME,
reviewer_id BIGINT,
PRIMARY KEY (team_id),
FOREIGN KEY (contest_id) REFERENCES contest(contest_id),
FOREIGN KEY (captain_id) REFERENCES user(user_id),
FOREIGN KEY (reviewer_id) REFERENCES user(user_id),
UNIQUE (invite_code)
)
主键 ：team_id
外键 ：
contest_id → contest(contest_id)
captain_id → user(user_id)

 )
主键 ：member_id
外键 ：
team_id → team(team_id)
user_id → user(user_id)
3.1.6 教师指导表（teacher_contest）
关系模式 ：
eacher_contest (
id, 
teacher_id, 
contest_id, 
create_time
)
主键 ：id
外键 ：
teacher_id → user(user_id)
contest_id → contest(contest_id)
